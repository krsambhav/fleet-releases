# Fleet releases

Download the latest Fleet desktop installer from [Releases](https://github.com/krsambhav/fleet-releases/releases/latest).

Available for macOS Apple Silicon and Windows x64. Fleet 0.4.14 and later include Settings → Check for updates. Checks and downloads are manual and do not require a GitHub account.

This repository distributes installers and update metadata only. Source development is private. Installers are currently unsigned. On Mac, open the DMG and drag Fleet into Applications; on Windows, run the installer. Keep your workspace data when upgrading.
